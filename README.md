# MG4
## Devlog
The Start() method sets things up when the game starts. Then Update() runs every frame to make the food move up and down. The _up variable checks if the food should go up or down, and _timer keeps track of time. When the timer reaches a certain point, the food changes direction. This keeps repeating, so the food looks like it's floating in the water.
